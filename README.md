# 📌 Project Overview

The **AI Sentiment Analysis Dashboard** is an end-to-end **Natural Language Processing (NLP)** project that classifies customer reviews into **Positive**, **Neutral**, or **Negative** sentiments.

The project demonstrates the complete machine learning lifecycle, from text preprocessing and feature engineering to model training, evaluation, and deployment using **Streamlit**.

# 📊 Machine Learning Models

The project compares the performance of multiple classification algorithms:

- Logistic Regression
- Multinomial Naive Bayes
- Random Forest Classifier
- Linear Support Vector Machine (Linear SVC)
- XGBoost Classifier

The best-performing model is selected based on evaluation metrics.

---

# 🧹 Text Preprocessing

The following preprocessing steps are applied before training:

- Convert text to lowercase
- Remove punctuation
- Remove numbers
- Remove special characters
- Remove unnecessary spaces
- TF-IDF Vectorization

# 💻 Installation

Clone the repository

```bash
git clone https://github.com/selvakumaran-datascience/AI_Echo_Your_Smartest_Conversational_Partner_sentiment_analysis.git
```

Move into the project directory

```bash
cd AI_Echo_Your_Smartest_Conversational_Partner_sentiment_analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Streamlit application

```bash
streamlit run chatgpt.py
```
